# Time Cmd — Documentation

`time-cmd` runs a command line and prints how long it took, in
milliseconds:

```
time-cmd fabricare make
...output of fabricare make...
Execution time: 48213 ms
```

It is a small command line tool for **benchmark purposes**: timing a build,
a test run, a script, a compression job, with the same command on Windows
and Linux. It is not a library: there is no API to link against, only the
`time-cmd` executable (the C++ class behind it is described in
[Reference](reference.md) for people working on the tool itself).

```
time-cmd              <-- this tool
xyo-system            (IApplication, DateTime, String)
xyo-encoding, xyo-multithreading, xyo-data-structures,
xyo-managed-memory, xyo-platform
```

## Why it exists

Every shell has some way to time a command, and every one is different:

| Shell | Built-in way | Problem |
|-------|--------------|---------|
| `cmd.exe` | none (`echo %time%` before and after) | manual, 10 ms resolution, breaks at midnight |
| PowerShell | `Measure-Command { ... }` | hides the command's output, prints a `TimeSpan` object |
| bash | `time ...` | three numbers (real / user / sys) in a format that depends on the shell and `TIMEFORMAT` |
| `sh` / `dash` | none (`/usr/bin/time` if installed) | not always present |

`time-cmd` gives one answer, in one format, everywhere:

| Need | What `time-cmd` does |
|------|----------------------|
| Same command on Windows and Linux | runs the command line through the system shell (`cmd.exe` / `/bin/sh`) on both |
| See the command's output while it runs | the command writes straight to the console; nothing is captured or hidden |
| One number that a script can read | prints one line, `Execution time: <N> ms`, after the command ends |
| Keep the result of the command | exits with the command's exit code, so `time-cmd make && next-step` still works |
| No installation of extra tools | one small executable; the static Windows build has no DLL dependencies |

## Concepts at a glance

| Need | Command |
|------|---------|
| Time a command | `time-cmd <command> [arguments ...]` |
| Time a command with shell operators (`&&`, `\|`, `>`) | `time-cmd "make && make test"` — quote the whole command line |
| Time a program whose path has spaces (Windows) | `time-cmd "\"C:\Program Files\Tool\tool.exe\" --run"` |
| Measure the overhead of `time-cmd` + shell | `time-cmd` with no command (Windows: about 20 ms, Linux: 1–3 ms) |
| Version / help / license | `time-cmd --version`, `--help`, `--usage`, `--license` |
